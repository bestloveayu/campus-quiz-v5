# V5 多場域校園編輯器

## 新增：學生一鍵匯出離線遊戲 ZIP

本版在編輯器頂端增加 **「📦 匯出遊戲 ZIP」**；「TXT 工坊」底部也有 **「📦 匯出完整遊戲 ZIP」** 按鈕。

1. 在新版本編輯器匯入 TXT，按「解析並預覽」及「確認套用」，或直接建立作品；題庫可以繼續在線上編輯器調整。
2. 編輯完成，按「📦 匯出遊戲 ZIP」。系統會先檢查作品流程、場景配置及題庫，再於瀏覽器內產生並下載 ZIP。
3. **學生下載的 ZIP** 內有 `index.html`、`執行遊戲.cmd` 和 `README.txt`；在 Windows 解壓縮後雙擊 `執行遊戲.cmd` 即可玩，不必安裝 Python，也不必連網。
4. 學生作品 ZIP 是單獨的**遊戲版**，不包含編輯器；要讓學生下次繼續編輯，請另外按「下載完整編輯存檔」保留 JSON，或保存原始 TXT。只在同一台、同一瀏覽器編輯會自動儲存，但**不會跨電腦同步**。
5. 將本份**編輯器原始碼**上傳 GitHub Pages 時，請上傳全部檔案，包含 `offline-player-template.html` 與 `vendor/jszip.min.js`，才能在網頁上使用 ZIP 匯出。

提醒：遊戲 ZIP 中的題庫及正確答案均位於 HTML，不適合用於答案必須保密的正式測驗。`執行遊戲.cmd` 是開啟本地 HTML 的捷徑，不會啟動服務或安裝程式。

本機網址：**http://127.0.0.1:3034/**。雙擊「啟動編輯器.cmd」後保持服務視窗開啟。V4（3032）與原檔保留，V5 使用獨立儲存鍵。

為避免舊版 V5 持續占用 3034，本次**獨立測試版使用 3035**。解壓縮到新的資料夾後，雙擊 `START-V5-DOORS.cmd` 啟動，接著打開 **http://127.0.0.1:3035/**（不是 3034）。看到互動流程上方「🚪 門與解鎖」才是新版。本版需安裝 Python 3。

**既有作品備份：** 3034 與 3035 是不同網站來源，不會共用瀏覽器的本機存檔。請先回到舊版 3034 點「下載完整編輯存檔 ↓」匯出 JSON，再在新版 3035 點「開啟編輯存檔（JSON）↑」匯入；不要在未備份時清除瀏覽器資料。

## 新增：3D 門、按 E 進出與開門條件

1. **校園入口**：走到耕莘樓前的門口，畫面出現「按 E 選擇場域」。按 `E` 或點互動按鈕開啟門廳，選擇教室、圖書館、護理技能教室等場域；未揭露或未解鎖的入口會說明原因。
2. **室內出口**：教室、圖書館、護理技能教室模板前方都有立體門；靠近出口按 `E` 返回校園。花園模板有出口拱門。單一固定場域模式不可透過出口繞出。
3. **教師設定**：在下方「互動流程」按 **🚪 門與解鎖**，每個場域可設定「自由通行」、「完成指定互動點」或「取得指定道具」。再按「套用場域與視野設定」儲存。
4. **授予道具**：點選任一知識站／NPC／挑戰桌／終點，在右側「完成後獲得的通行道具」填寫名稱（例如「護理通行證」）。名稱必須與門設定完全相同。挑戰通過才算完成，不會因答錯發放道具。
5. **舊作品**：逐步揭露／全部顯示／固定場域仍生效；迷你地圖和「前往目前任務」會檢查門鎖。舊 JSON 沒有門條件時預設自由通行。

門是風格化立體幾何模型，切換場域時直接傳送，不含開門動畫；通行道具是任務憑證，不提供背包或消耗功能。

## 這次怎麼操作

### 1. 調整版面

- **左面板**：拖面板右側細把手改寬度；右下角可調整寬高。
- **右面板**：拖面板左側細把手改寬度；右下角可調整寬高。
- **流程視窗**：拖上緣中央把手往上放大、往下縮小；右下角可改寬度／高度。
- 每個面板有收合按鈕；流程視窗可按「收合流程」，讓 3D 編輯畫布變大。
- 「還原版面」恢復預設。面板和流程占用的空間會從 3D 畫布扣除，桌面版不會以流程圖蓋住編輯畫面。
- 迷你地圖的標題列可拖曳移動，右下角可縮放，右上角可收合。
- 建議桌面大視窗建構。窄視窗預設收合面板與流程，可各別展開；尚未做實際手機觸控驗收。

### 2. 流程圖自由編排與改變順序

- 拖曳模式選「自由編排」：拖動節點到任意 X/Y 位置；放開後更新連線，位置會保存。
- 空白處拖曳可平移；工具列的 −／＋ 放大縮小，「適合視窗」縮放到合適大小；Ctrl＋滾輪也可縮放。
- 選「調整排列順序」：把卡片拖到另一個卡片位置，更新排列順序並排整齊。
- **排列順序不會默默改掉劇情分支。** 要依排列順序執行，另按「依排列順序串接任務」。這會把人物選項串到下一站、通關到下一站、未通關留在本關；終點須在最後。
- 若只改一條分支，按節點的「＋」再點目標，或在右側選擇下一站。
- 修改可用「復原／重做」；「檢查流程」可檢查連線、前置條件及場域解鎖循環。

### 3. 新增不同場域

左側場域下拉選單旁按「＋ 場域」：

1. 下方填名稱，選擇模板，再按「新增獨立場域」。
2. 可選 **校園校舍、花園廣場、教室、圖書館、護理技能教室**，最多 16 個場域。
3. 每個場域有自己的素材與碰撞。可用同一模板建立不同房間，再分別布置。
4. 關閉視窗，從左側選素材、點地板放置。右側「所在場景」可將素材搬到其他場域，但位置必須可放置。
5. 下拉選單或迷你地圖可切換場域；編輯模式可編輯所有場域。
6. 移除場域前須先移走／刪除其素材。刪除解鎖任務時會清理引用，避免作品變成無效狀態。

模板是風格化示意，並非根據現況照片精確重建，也不是任意建築建模工具。

### 4. 三種視野／迷你地圖模式

在迷你地圖選模式，或「設定／＋ 場域」中完整設定：

| 模式 | 試玩行為 |
| --- | --- |
| 逐步揭露場域 | 起點場域可見；完成各場域指定的解鎖任務後才揭露。未揭露場域顯示「未探索」，不能進入 |
| 一開始全部顯示 | 所有場域可探索；互動點仍依任務連線及前置條件開始 |
| 固定單獨顯示一間 | 只顯示指定場域，不能從入口或返回校園繞出；適合單間練習 |

「逐步」的單位是**依任務解鎖的場域**。本版沒有步行時逐格消除的霧效。

場域設定可複選需要先完成的互動點，或勾選「初始顯示此場域」。起點所在場域一定可見。若把解鎖條件搬進同一個尚未開放場域，會阻擋套用；場域相依循環也會提示。

固定模式保留原任務條件，不會自動取消其他場域的前置條件。若要獨立單間練習，請使用 examples/08-fixed-room.json，或安排一條在同一場域內可完成的路線。

### 5. TXT 匯入後繼續自由編輯

- 「TXT 工坊」匯入方式與 V4 相同，可先載入完整三關範例、選「替換」再預覽與套用。
- 匯入後素材、新增人物、複製、移除、流程連線均可繼續編輯，不再鎖住。
- 相同作品編號再次套用 TXT，會保留額外加入的素材、場域、原有座標和流程圖位置；已手動延伸的路線保留。
- 不同作品編號視為另一個作品。不要期待自動合併兩個不同作品。
- TXT 適合交換原始關卡設計和題庫；**新增場域、進階分支、自由配置與歷程請用完整編輯存檔保存**。

### 6. 儲存與開啟新編輯存檔

- 上方 **「另存新作品」** → 輸入名稱 →「建立副本並下載」。新作品有獨立編號。
- 左側「下載完整編輯存檔」下載目前作品；檔案為 JSON，學生不必閱讀或編寫內容。
- 上方 **「開啟存檔」** → 選 JSON →「驗證並匯入」。支援 V3／V4 舊完整備份及 V5 存檔。
- 完整檔含場域、模板、素材、流程位置／排列／連線、視野、左右面板與迷你地圖布局、題庫、對話製作紀錄及試玩歷程。
- 匯入會還原布局；缺少布局的舊備份會使用預設尺寸，可按「還原版面」。
- 本機自動保存仍受瀏覽器容量與網址限制，換電腦／網址請帶完整檔。

## 邊界與部署

無 AI API、GAS 或雲端同步；本版是本機保存／下載存檔。新增模板不需付費 AI。

可將 index.html、CSS、JS/MJS、vendor/、examples/、.nojekyll 一起放到靜態網頁發布目錄。全部為相對路徑，不需在網站執行 Python。此次沒有發布 GitHub。

PDF／Word 與原題庫功能沿用瀏覽器端讀取，掃描 PDF 仍需另外 OCR。擷取文字不代表任意排版能自動成為題庫。

自動測試與實測記錄見 QA.md、QA-tests.txt。Three.js、PDF.js、Mammoth 的授權文件在 vendor/。
# V5.2.1 更新（2026-10-31）

- 知識站與挑戰桌的「分流出口」改為一致的「＋ 增加選項」，可新增最多八個選項，或使用原本的單一路線。
- 每一個選項可用「從這個選項連線」直接指定互動流程目標，箭頭與設定同步。
- 條件分流支援分數達標／未達標、已完成關卡及持有道具；符合條件時會先自動分流，其餘路線由學生自行選擇。
- 答題未通過時也會檢查條件路線；沒有適用出口則沿用原本的補救路線。
- 人物對話維持原有多對話選項；任務終點完成即結束回合，不提供離開終點的箭頭。
- 更新前請保留現有 TXT 作品與完整 JSON 進階備份，升級不會主動覆寫瀏覽器中的編輯作品。
