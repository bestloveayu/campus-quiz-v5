# Campus Doors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** Add visible doors, E travel and task/item locks while preserving V5 saves.

**Architecture:** `studio-core.mjs` evaluates policies; `flow-core.mjs` grants items; `studio.js` and `author.js` provide authoring and travel; `world.js` adds 3D meshes and near points.

**Tech Stack:** Static HTML/JS, Three.js, Node.js test runner.

**Spec:** `docs/superpowers/specs/2026-10-31-doors-design.md`

## Global Constraints
- Legacy JSON and auto-save keys stay compatible.
- Doors and mini map must respect visibility and locks.
- No new dependencies.

## Review Focus
- Legacy V5 backups remain playable.
- Challenge failure never grants items.
- Hidden destinations do not leak names.
- Fixed-mode exits remain blocked.
- Removed prerequisites cannot silently block forever.
